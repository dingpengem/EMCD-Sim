# Source-spectrum visualization helpers

Only `plot_wien2k_xmcd.py` and `plot_wien2k_xmcd_suite.py` remain here. They
inspect/plot the original source spectrum and do not calculate EMCD. Run either
with `python scripts/research/<name>.py --help` from the repository root.

The former atomic-slicing, fractional-aperture and [017]/[710] study drivers
have been deleted, not archived in another source directory. Use their original
Git revisions for historical studies. Numerical outputs and original figures
remain preserved. See [the production source audit](../../docs/SOURCE_CLEANUP.md).
