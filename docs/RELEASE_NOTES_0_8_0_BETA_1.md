# EMCD-Sim v0.8.0-beta.1 — Windows-only Research Beta

This prerelease adds unified neutral-atom **elastic** scattering to the portable Windows application. Download the complete [Windows ZIP and SHA256SUMS.txt](https://github.com/dingpengem/EMCD-Sim/releases/tag/v0.8.0-beta.1), verify the archive checksum and extract the full folder. Keep `_internal` beside `EMCD-Sim.exe`. The unsigned application includes its Python runtime; Python, Conda and WIEN2k are not required on the target machine.

New GUI calculations default to **Adaptive Dirac–Padé 2026, neutral Z=1–118**. Ordered multi-element CIF elastic diffraction supports non-FCC cells, including BCC Fe, CsCl (100), hexagonal ZnO and monoclinic cells. Labels and clicked hkl use the imported three-index cell basis. Partial/disordered occupancies and four-index Miller–Bravais entry remain unsupported.

**Ni Lobato 2014** remains selectable and its implementation is unchanged. Historical saved settings without a provider field restore Lobato explicitly; they are never silently migrated to Adaptive. The original unversioned Python potential constructor retains Lobato compatibility. New projects preserve provider identity, coefficient digest and conventions. Select Lobato explicitly to reproduce the existing [Ni 9/30 nm case study](TUTORIAL.md#part-vii-practical-ni-017-case-study): its verified recalculated arrays and figures are unchanged, with raw EMCD a.u. primary and normalized percentages supplementary.

The original **Ni-specific inelastic MDFF/EMCD restrictions remain in force**. General elastic factors do not supply general-material MDFF. The XMCD-constrained model still requires verified conventional FCC Ni. No Ni event/MDFF kernels or physical conventions change in this release.

The bundled coefficient subset is separately [Apache-2.0](../src/emcd_sim/data/adaptive_dirac_pade_2026/LICENSE), with [NOTICE](../src/emcd_sim/data/adaptive_dirac_pade_2026/NOTICE) and [pinned provenance](../src/emcd_sim/data/adaptive_dirac_pade_2026/provenance.json). EMCD-Sim code remains MIT. The JSON evaluator needs no HDF5 runtime or upstream HDF5 archives. The unlicensed legacy Z=1–98 table is **not bundled**; its external-data adapter retains source-compatible interpolation and documented numerical reliability guards, including the XF/Mott low-g exclusion. See [provider units, ranges and limitations](ELASTIC_ATOMIC_FACTORS.md).

The v0.8.0-beta.1 tag identifies the **exact accepted Windows build-source commit**. About/build information and the build manifest record that identity. Version metadata is Python `0.8.0b1`, display `v0.8.0-beta.1`, Windows numeric `0.8.0.1`. Later acceptance-report commits do not change the executable source. The [Windows acceptance report on main](https://github.com/dingpengem/EMCD-Sim/blob/main/docs/WINDOWS_0_8_0_BETA_1_ACCEPTANCE.md) records source tests, actual extracted-EXE checks, manifest verification and archive hashes. The previous v0.7.0-beta.1 release and assets remain intact.

This is a **Windows-only prerelease**, not a stable or cross-platform-certified release. Linux retains a Python shutdown `bool_dealloc` abort; macOS tests stall at a Qt modal preflight dialog. These CI failures remain visible and are not gates for this Windows-only release. No Linux/macOS packaged application is offered.

Numerical compatibility, bounded BW/MS comparisons, physical accuracy and Windows application functionality are distinct. Selected BW/MS agreement does not establish broad convergence. Neutral independent-atom factors omit bonding/ionic redistribution and do not validate experimental quantitative scattering. The projected finite-ZOLZ model, cutoffs, approximate Ni MDFF and uncalibrated absolute handedness/cross sections retain their limitations. Independent clean-machine Windows installation and experimental quantitative accuracy remain unverified. No expensive historical studies were rerun for this release.
