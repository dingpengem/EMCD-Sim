# P2: complex MDFF from transition amplitudes (v0.4.0)

**Current implementation:** a mathematical tensor builder from **supplied** complex dipole transitions. **It is not an all-electron DFT solver or a validated Ni magnetic MDFF.** The synthetic L3/L2 example intentionally contains invented transition amplitudes and is for code tests only. Current default `emcd-ni` still uses illustrative Gaussian N(E), M(E).

## Mathematical definition and phase convention

Define each transition's **complex** Cartesian dipole `d_n,a = <i|r_a|f>` in Angstrom, with initial core state i and unoccupied final state f. This convention is fixed in the dataset. Define *angular* momentum transfer `Q` in rad/Angstrom. The spectral dipole tensor (no Coulomb factors) is:

`T_ab(E) = sum_n w_n d_n,a conj(d_n,b) G_sigma(E - E_n)`, with unit-area Gaussian `G_sigma` in 1/eV and nonnegative transition weights `w_n` (occupied core, unoccupied final state, k-point and any statistical weights).

`S_dip(Q,Q',E) = sum_ab Q_a T_ab(E) Q'_b`.

Here `Q = 2*pi*g` converts the EMCD-Sim crystallographic **cycles/Angstrom** coordinate g to angular `rad/Angstrom`. Any matrix-element exporter needs to follow the stated `d=<i|r|f>` convention or conjugate its amplitudes accordingly. The MDFF itself **does not include** the Coulomb `1/(Q^2 Q'^2)` terms, physical scattering prefactors or site-specific crystal phases. The code emits units of **Angstrom²/eV** for the tensor (transition weights dimensionless), and a dipole MDFF in **1/eV** for angular Q in inverse Angstrom. It is not a measured cross section.

The Hermitian Gram-matrix form guarantees `T(E)=T(E)†` and nonnegative eigenvalues for nonnegative weights; `S(Q,Q',E)=conj(S(Q',Q,E))` and `S(Q,Q,E)>=0`. `Im(T_xy)` is an example of a chiral component, whose sign depends on handedness and phase conventions. Replacing all dipoles with their complex conjugates reverses the imaginary components in the *toy model*; real magnetization reversal may also modify the underlying electronic structure.

## Portable transition file (NPZ; `allow_pickle=False`)

Required arrays:

| Field | Shape | Meaning |
|---|---|---|
| `energy_ev` | `(n,)` | Positive core-to-final energy losses in eV |
| `dipoles_angstrom` | `(n,3)`, complex | `d=<i|r|f>` Cartesian dipoles; retain complex phases |
| `weights` | `(n,)`, nonnegative | occupation × k weight × other nonnegative factors |
| `edge` | `(n,)`, Unicode | `L3`, `L2`, etc. |
| `site` | `(n,)`, Unicode | local scattering center / site group |
| `source` | scalar string | Required provenance (DFT package, run, functional, SOC etc.) |
| `convention` | scalar string | Fixed phase/units protocol, generated by `TransitionDataset.save_npz()` |

An electronic structure adapter must also document exchange-correlation functional, SOC implementation, core-state splitting, k/band convergence, core-hole treatment and wavefunction normalization. **The present importer cannot infer these facts from raw DOS or ELNES.** It does not magically turn ordinary ELNES intensities into the complex non-diagonal MDFF. For site-resolved comparisons, first filter by site; full-crystal site phases belong in a future single-channeling coupling module.

## Usage

```bash
python -m emcd_sim.mdff_reference --toy --output outputs/mdff_toy
python -m emcd_sim.mdff_reference --transitions your_transitions.npz --sigma-ev 0.8 --output outputs/from_dft
```

With Python:

```python
import numpy as np
from emcd_sim.mdff_tensor import TransitionDataset, dipole_tensor_from_transitions

data = TransitionDataset.load_npz('your_transitions.npz')
E = np.linspace(845., 880., 200)
tensor = dipole_tensor_from_transitions(data, E, sigma_ev=0.8, edge='L3')
Q = np.array([1., 0., .2])  # angular rad/Angstrom, NOT crystallographic cycles/Angstrom
Qp = np.array([0., 1., .2])
S = tensor.mdff(Q, Qp)  # complex, shape (200,)
```

## Reference software and practical limits

1. [abTEM core-loss tutorial](https://abtem.github.io/doc/user_guide/tutorials/core_loss.html) and [Python source](https://github.com/abTEM/abTEM/blob/main/abtem/inelastic/core_loss.py). Strong reference for atomic core-loss transition potentials and multislice/single-channeling (with GPAW and sympy). Ordinary abTEM core-loss does **not** automatically provide spin-polarized Ni L2,3 magnetic MDFF with verified SOC.
2. [Elk `elnes.f90`](https://elk.sourceforge.io/doxygen/html/elnes_8f90_source.html) and `genexpmat` for *actual* complex electronic excitation matrix elements. Its ELNES routine typically squares each matrix element, so it does **not**, by itself, export a full off-diagonal complex MDFF. Extending Elk requires wavefunction/phase handling, relativistic Ni 2p core-to-band transitions and magnetic validation.
3. [Rusz, Rubino, Schattschneider, PRB 75, 214425 (2007)](https://doi.org/10.1103/PhysRevB.75.214425), first-principles theory for 3d ferromagnets (including Ni), as an analytical and physical baseline.

Reference implementations have different licenses. **Do not paste third-party GPL code into the MIT repository.** This P2 implementation is independently written using NumPy and publicly documented formulas.
