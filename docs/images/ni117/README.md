# Ni [117] scientific preview images

These are compressed previews of actual saved simulations/analyses, not new
calculations. `provenance.json` records each original local PNG path and SHA256.
Original PNG/SVG, raw NPZ/CSV and checkpoints remain under the documented
`outputs/` directories and are intentionally not added to the source repository.
Captions and numerical scope are in the two Ni [117] validation reports.
The previews do not certify universal convergence or experimental accuracy.
