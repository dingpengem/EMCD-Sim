# Windows installation

[Home](../README.md) · [Quick Start](QUICK_START.md) · [Tutorial](TUTORIAL.md) · [User Manual](USER_GUIDE.md)

These instructions apply to the public **v0.8.0-beta.1 Windows Research Beta**, with the unified neutral-atom elastic provider. The application is unsigned beta research software. Native automated Windows acceptance passed; independent installation on a separate clean PC or VM has **not been tested**.

## A. System requirements

- A 64-bit Windows computer. The release package was built with the recorded Python 3.11 Windows toolchain; this does not certify every Windows version or machine configuration.
- CPU execution; no GPU or separate Python/Conda/WIEN2k installation is required for the portable ZIP.
- A writable extraction directory, space for complete projects and sufficient available RAM for the chosen configuration. The default **2048 MiB estimated process budget is not a minimum system-RAM specification**.
- Enough screen space for Settings, Diffraction and Results. Resize the window, scroll Settings, collapse sections or maximize a viewer if needed.

Larger bases and Double Channeling can require substantially more time/memory. The application checks estimated process peak against both the selected budget and a conservative fraction of available RAM; it does not silently lower scientific settings to fit.

## B. Download the correct release

Open [v0.8.0-beta.1](https://github.com/dingpengem/EMCD-Sim/releases/tag/v0.8.0-beta.1) and download both assets:

- [EMCD-Sim-v0.8.0-beta.1-Windows.zip](https://github.com/dingpengem/EMCD-Sim/releases/download/v0.8.0-beta.1/EMCD-Sim-v0.8.0-beta.1-Windows.zip)
- [SHA256SUMS.txt](https://github.com/dingpengem/EMCD-Sim/releases/download/v0.8.0-beta.1/SHA256SUMS.txt)

Do not substitute GitHub's autogenerated **Source code** ZIP/TAR: those are source archives, not the portable application. The Actions artifact has a separate outer wrapper; the public release asset above is already the inner portable ZIP. Its checksum is not the wrapper checksum. Use version-specific links rather than assuming GitHub's “latest” stable-release route selects this prerelease.

## C. Verify the download

Open PowerShell in the download directory:

```powershell
Get-FileHash -LiteralPath '.\EMCD-Sim-v0.8.0-beta.1-Windows.zip' -Algorithm SHA256
Get-Content -LiteralPath '.\SHA256SUMS.txt'
```

The ZIP hash must exactly match its entry in SHA256SUMS.txt downloaded from the same version-specific release (letter case is irrelevant). The release page and [acceptance record](https://github.com/dingpengem/EMCD-Sim/blob/main/docs/WINDOWS_0_8_0_BETA_1_ACCEPTANCE.md) also record the accepted digest. Do not reuse the checksum from an older release.

A mismatch means this is not the accepted archive. Do not use it as that candidate; obtain a fresh copy from the version-specific release and verify again.

## D. Extract the complete portable ZIP

Use Windows **Extract All…** into a normal writable folder, for example a user-owned applications directory. The extracted application has this structure:

```text
EMCD-Sim/
    EMCD-Sim.exe
    _internal/
    ...other bundled files...
```

Keep the entire directory intact. Do not run inside the ZIP, copy just the EXE, merge `_internal` from another version or overwrite an older installation in place.

## E. Launch EMCD-Sim

Open the extracted `EMCD-Sim.exe`. Windows may warn about an unsigned or unfamiliar application. Check the download origin and hash and follow your organization's software policy. Native acceptance is not code signing or SmartScreen certification. Do not disable antivirus or other security protections.

The first window should show collapsible Settings, the central Diffraction viewer and Results. Use **View → Restore Default Layout** if a saved layout is unsuitable for your monitor.

## F. First-run verification

1. Open **Help → About** and inspect the application/build information: display version **v0.8.0-beta.1**, package version **0.8.0b1**, a binary source commit matching the **v0.8.0-beta.1 tag target** and convention **forward_born_dagger_g_minus_h_v1**.
2. Confirm current unit labels: kV, nm, mrad, eV, Å⁻¹, a.u., %, and MiB. The live diffraction viewer uses a yellow ZA star, teal dotted Thales circle and darkorange dashed ZOLZ Laue circle.
3. Follow the [small Quick Start](QUICK_START.md), save its completed project, then reopen it. This is a functional check, not scientific convergence validation.

The v0.8.0-beta.1 tag targets the exact accepted EXE source commit. Later documentation commits on main do not rewrite the embedded build provenance. This release is Windows-only: Linux/macOS are not certified packaged platforms. The original v0.7.0-beta.1 release and its assets remain available unchanged.

## G. Update to a newer version

Download and verify the new version into a **new** directory. Keep the old application and scientific projects until compatibility/provenance have been checked. Do not overwrite a project's arrays to make them appear to come from newer physics.

> **Legacy magnetic signs:** released v0.6.1 betas used a superseded Born/MDFF convention. Signed magnetic spectra need revalidation before comparison with corrected results. Opening an old project does not recalculate or upgrade its physics. Missing convention metadata remains unknown/legacy-unverified.

## H. Projects, application data and logs

Store research projects in user-owned directories separate from the extracted application. **File → Save Project As...** saves a completed numerical result as a complete checksummed folder; it is not a save of arbitrary uncalculated Current Inputs. Keep all JSON/CIF/NPZ files together. A figure or Results Browser index is not a project backup.

Default application paths are:

|Purpose|Default Windows path|
|---|---|
|Application data|`%LOCALAPPDATA%\EMCD-Sim`|
|Workspace/index/UI preferences|`%LOCALAPPDATA%\EMCD-Sim\workspace` (`results_index.json`, `ui.ini`)|
|Runtime log|`%LOCALAPPDATA%\EMCD-Sim\logs\runtime.log` (rotated backups)|
|Native fault traces|`%LOCALAPPDATA%\EMCD-Sim\logs\native_fault_<pid>.log` when enabled; may be empty on normal runs|

The workspace can be explicitly redirected with `EMCD_GUI_WORKSPACE`; application logs remain under the application-data directory. Reopening saved arrays does not require a new calculation. Rerunning may require locating original source files with matching SHA256. See [project management](USER_GUIDE.md#project-management).

## I. Troubleshooting

|Symptom|Action|
|---|---|
|Missing Python/DLL/Qt files or immediate startup failure|Verify the ZIP hash and extract a fresh **complete** directory. Check whether security software quarantined a dependency and follow local policy; do not combine files from different packages.|
|Window appears but controls/plots are cramped|Resize, scroll, collapse chevrons or use **View → Restore Default Layout** and viewer maximize/restore buttons.|
|Preview is gray or marked stale|Geometry changed after the last preview. Click **Preview diffraction**. Gray indexed positions are not new computed intensities.|
|Run disabled|Validate the source/declaration; inspect the resource/status explanation and unsupported-structure/geometry messages.|
|Memory admission rejected|Read the estimated peak, selected budget and available-RAM limit. Free RAM or explicitly choose supported settings; increasing a budget alone does not create RAM.|
|Saved result opens but rerun is disabled|Use **Results → Locate Original Source...** to locate the checksum-matching source; keep viewing original arrays without recalculation.|
|Older result displays a physics-convention warning|Preserve its original data; do not treat loading as scientific revalidation.|

To locate logs in PowerShell:

```powershell
explorer "$env:LOCALAPPDATA\EMCD-Sim\logs"
```

For a reproducible issue, record the exact package/source identity, OS, requested/effective configuration, visible error and relevant logs. Avoid sharing unrelated personal paths/data. Linux/macOS standalone packages are not supplied or certified by this Windows prerelease; source CI limitations are documented in the [acceptance record](WINDOWS_ZOLZ_97B2220_CANDIDATE_ACCEPTANCE.md).

## J. Advanced installation from Python source

This is a separate workflow, for researchers/developers with Git and a suitable Python installation. The package requires Python ≥3.10; the accepted Windows build used **3.11.9**. Source on current main may have documentation newer than the binary; inspect the commit rather than relying on version alone.

With Git, Python 3.11 and the Windows Python launcher installed, use PowerShell in a directory where a new clone is appropriate:

```powershell
git clone https://github.com/dingpengem/EMCD-Sim.git
Set-Location EMCD-Sim
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[gui]"
.\.venv\Scripts\python.exe -m emcd_sim.gui
```

Using the virtual-environment interpreter directly avoids requiring shell activation. If `py` is unavailable, invoke your chosen Python 3.11 interpreter by its explicit path; do not accidentally use an older system Python. NumPy/Matplotlib are core dependencies; PySide6 and ASE are installed by the `gui` extra. `emcd-gui` is the installed launcher. The companion transition/atomic input utilities do not run DFT or provide a complete DFT Ni MDFF.
